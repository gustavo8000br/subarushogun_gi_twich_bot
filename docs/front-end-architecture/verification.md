# Verification

The OPS-15 migration matrix maps every screen/action, API endpoint, locale/catalog dependency, state and test ID before the legacy frontend is removed. The Next dev proxy must be limited to a validated loopback origin, trust the generated local CA when available, and remain absent from production export. Verify `trailingSlash: true` route artifacts (`/x/` -> `out/x/index.html`), the postbuild `out/overlay.html` alias, direct refresh and asset loading through `@fastify/static`, and explicit Fastify route precedence with no SPA fallback. Package and test the `.local/community-catalogs` read-only mount in each unified installer; add a complete locale after image build and prove panel/setup/chat discovery on the next lookup and overlay discovery within the five-second cache TTL. Tests also cover same-origin security contracts, panel/overlay bundle separation, localized form and operation states, and existing keyboard, focus, contrast and FND-7 editor WCAG AA criteria. Keep Host/Origin, session, CSRF, authorization, privacy projection and mutation correctness under backend route/integration tests.

Next panel foundation contracts verify session initialization before protected reads, safe same-origin API errors, CSRF/idempotency headers on writes, expected-revision locale updates, runtime catalog normalization, and use of the protected operator `GET /api/queues` projection. Invalid queue projections must fail visibly instead of becoming a zero-count summary. The first-party pt-BR server-render fallback does not replace runtime catalog discovery or persisted locale reads.

Overlay browser tests retain the exact `/overlay.html?ref=...#token` URL and cover fragment removal, per-ref `sessionStorage`, bearer capability without panel session, 401/403/404 clearing, stale projection retention, unload/reload and revoke/rotate. Performance evidence retains FND-7's target of eight sources and ten updates within two seconds. Validate exported assets served by Fastify in isolated Compose with disposable PostgreSQL. Native OBS/CEF evidence must identify the tested platform and versions; do not claim unrun checks.

The first implementation slice adds an integration contract for the static export, route files, literal overlay alias, route-specific client bundles, root-relative assets, Fastify callback/API/health precedence and static serving. The dedicated Next overlay now mounts the existing renderer, and the Docker frontend build explicitly includes that module. Production Fastify still serves the legacy web root. Development command contracts verify that `npm run dev` configures separate API/frontend ports, loopback API binding, TLS paths, the same-origin proxy, and a required explicit database URL; a disposable PostgreSQL runtime check remains required before claiming live combined startup. The OPS-13/#57 authorization/URL conflict remains open; this increment preserves the current capability contract and does not decide that conflict.
