# Non-goals
[Português brasileiro](../pt-BR/prd/non-goals.md)


No public signup, viewer join command, game credentials, UID verification, Discord/DM, public/external overlay service, ranking, multiple channels/apps/bot accounts, hosted backend/database, telemetry, export/backup feature, horizontal scaling, or IRC. The local OBS overlay is a product surface. OPS-15 permits Next.js App Router served by the local Next.js server (no static export), which forwards same-origin API requests to the loopback Fastify API; browser application code remains JavaScript ESM with JSDoc, with no TypeScript application code.
