# Non-goals
[Português brasileiro](../pt-BR/prd/non-goals.md)


No public signup, viewer join command, game credentials, UID verification, Discord/DM, public/external overlay service, ranking, multiple channels/apps/bot accounts, hosted backend/database, telemetry, export/backup feature, horizontal scaling, or IRC. The local OBS overlay is a product surface. OPS-15 permits Next.js App Router and its build-time transpilation/bundling only for a static export served by local Fastify; browser application code remains JavaScript ESM with JSDoc, with no TypeScript or Next.js runtime server.
