## 0. Verdict

**CONCERNS, 9.1/10 for the delivered slice** (the seven new browser scripts, the Compose E2, the FT-06 matrix as a document, and E7). Gate minimum 9.0 met. **LA-01 is not closed** and **feature 17 stays N** (E8 native OBS/CEF is an owner blocker; the FT-06 box needs DTO and runtime evidence this matrix does not yet hold). No code was changed by `@qa`.

Why 9.1 and not higher:

- **C-1 (medium, accessibility):** `apps/frontend/styles/panel.css:551` (`.reference-feedback:empty { display: none; }`) removes the two copy-feedback live regions from the accessibility tree until text arrives. Measured in Chrome: the empty `role="status"` and `role="alert"` spans compute to `display: none`, and the card's aria snapshot lists only the paragraphs and the button. The plan (section 2.2, AC-E7.5) asks for regions that "exist from the first render and start empty so the announcement is reliable". The jsdom test passes because jsdom has no CSS. A region that appears with its text in the same frame is announced unreliably by several screen readers. Recommendation for `@dev`: keep the regions rendered (visually hidden when empty, for example a clip/1 px pattern) instead of `display: none`. Screen reader behavior itself is **not verified** (LB-05, accepted risk; Orca exists on this machine but was not driven in the owner's live desktop session).
- **C-2 (low, docs):** `docs/stories/OPS-15/route-action-matrix-remaining-families.md:13` (and the pt-BR twin, line 13) still says for STA-01 "initial-load failure does not render `referenceId`". E7 now renders it. Stale statement in a file meant to be a source of truth.
- The LA-01 criterion itself is only partly met (see section 5).
