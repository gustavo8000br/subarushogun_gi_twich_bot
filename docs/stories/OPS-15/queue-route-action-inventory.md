## Scope and evidence rules

This slice expands queue-list, queue configuration, attendance, reward recovery, and lifecycle routes from INV-05/06. Contracts were inspected in `apps/api/src/http/queue-routes.mjs`; assertion availability and execution are recorded in the matrices and current OPS-15 handoff. Shared security boundary QRA-S applies to QRA-01–QRA-23: `local-session.mjs` allows only the configured local Host and exact configured development Origin; `/api/*` except `/api/session` requires a local session (401), and unsafe methods except `/callback` require a matching CSRF token (403). Boundary tests: `tests/unit/local-session.test.js` “establishes a local session and requires its CSRF token for mutations”, “rejects insecure local origins on the HTTPS panel”, “accepts only the exact explicitly configured loopback HTTP origin for local Next development”, “rejects foreign Host and Origin values without reflecting them”, and “requires a local session for administrative GET projections while keeping health reachable”. Idempotency is covered by `queue-routes.test.js` “replays a mutation response for a repeated idempotency key without repeating its effect” and “rejects mutations that omit a valid idempotency key”. Queue mutation idempotency also applies to every mutating `/api/*` except `/api/session`: missing/invalid key or unavailable operation store returns 400/503; fingerprint conflict or in-progress returns 409. A replay restores the stored status/body and adds `idempotency-replayed: true`; it does not restore arbitrary response headers. Responses >=500 are not stored. Only explicitly listed `expectedVersion` fields provide version checks; absent one, the route/domain service is authoritative for conflict detection, and idempotency does not imply optimistic concurrency.

“Source/test mapped” means the handler and named test were inspected; it is not runtime evidence. The test names below indicate available assertions, not tests executed in this documentation increment. All runtime/browser cells remain Pending until run against the specified isolated environment. Route behavior, product policy, and schema are not changed by this inventory.
