Where the A column says "repository layer only", the test exercises the PostgreSQL repository, not the Fastify route. ## What the new rows rely on

- Browser scripts (B) use `tests/e2e/fixtures/panel-browser-harness.mjs`, which serves the REAL `en` and `pt-BR` panel TSV catalogs and intercepts only same-origin `/api` and `/health`; cross-origin requests are aborted and recorded, never followed. Each script prints its boundary.
- The new browser scripts found one real defect: `panel.command.conflict` was used by `/commands` on a 409 but absent from the `en`, `es` and `pt-BR` catalogs (only a unit test injected it). The key was added to the three catalogs.
- Not covered anywhere (open gaps to carry): REC-01, CMD-02, ACC-01/02, WID-03/06 in a browser; SET-01..04 and CMD in a real stack; the `/connection` disconnect flow does not exist in the panel, so none was tested.
