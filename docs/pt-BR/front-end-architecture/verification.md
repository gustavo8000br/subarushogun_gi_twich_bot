# Verificação
[English](../../front-end-architecture/verification.md)


A matriz de migração OPS-15 mapeia cada tela/ação, endpoint da API, dependência de locale/catálogo, estado e ID de teste antes da remoção do frontend legado. O proxy dev do Next deve limitar-se a uma origem loopback validada, confiar na CA local gerada quando existir e ficar ausente do export de produção. Verifique artefatos de rota `trailingSlash: true` (`/x/` -> `out/x/index.html`), alias postbuild `out/overlay.html`, refresh direto e carregamento de assets pelo `@fastify/static`, e precedência explícita do Fastify sem fallback SPA. Empacote e teste o mount somente leitura `.local/community-catalogs` em cada instalador unificado; adicione uma locale completa após o build da imagem e prove descoberta no painel/setup/chat na consulta seguinte e no overlay em até cinco segundos de cache. Testes também cobrem contratos de segurança same-origin, separação dos bundles painel/overlay, estados localizados de formulário/operação e critérios atuais de teclado, foco, contraste e WCAG AA do editor FND-7. Mantenha Host/Origin, sessão, CSRF, autorização, projeção de privacidade e correção das mutações sob testes de rotas/integração do backend.

Os contratos da fundação Next verificam inicialização da sessão antes das leituras protegidas, erros seguros do cliente API same-origin, headers CSRF/idempotência em escritas, atualização de idioma com revisão esperada, normalização de catálogos runtime e uso da projeção protegida de operador `GET /api/queues`. Projeção de fila inválida deve falhar de forma visível em vez de virar resumo zero. O fallback first-party pt-BR renderizado no servidor não substitui a descoberta runtime de catálogos nem a leitura do idioma persistido.

Os testes de navegador do overlay preservam a URL exata `/overlay.html?ref=...#token` e cobrem remoção do fragmento, `sessionStorage` por ref, capability bearer sem sessão do painel, limpeza em 401/403/404, retenção de projeção stale, unload/reload e revoke/rotate. A evidência de desempenho mantém a meta FND-7 de oito fontes e dez atualizações em até dois segundos. Valide os assets exportados servidos pelo Fastify em Compose isolado com PostgreSQL descartável. Evidências nativas OBS/CEF devem identificar plataforma e versões testadas; não alegue verificações não executadas.

O primeiro incremento de implementação adiciona um contrato de integração para export estático, arquivos de rota, alias literal do overlay, bundles client por rota, assets com caminhos absolutos na raiz, precedência Fastify para callback/API/health e serving estático. O overlay Next dedicado agora monta o renderer existente, e o estágio Docker do frontend inclui explicitamente esse módulo. O Fastify de produção ainda serve a raiz web legada. Os contratos do comando de desenvolvimento verificam que `npm run dev` configura portas separadas para API/frontend, bind da API em loopback, caminhos TLS, proxy same-origin e URL explícita obrigatória do banco; ainda é necessária uma execução integrada com PostgreSQL descartável antes de afirmar inicialização real dos dois serviços. O conflito de autorização/URL da OPS-13/#57 continua aberto; este incremento preserva o contrato atual de capability e não decide esse conflito.
