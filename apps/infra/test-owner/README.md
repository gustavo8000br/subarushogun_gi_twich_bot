# Owner test installer workflow / Workflow do instalador de teste do dono

**EN.** `windows-owner-test-installer.yml` must never live in `.github/workflows` on `main`. Only `@devops` copies it, once per test cycle, into the branch `test/windows-owner` as `.github/workflows/windows-owner-test-installer.yml`, together with an `apps/infra/test-owner/RUN-MARKER` file; the run starts only when a push changes one line of that marker (empty commits do not trigger), which waits for the owner's approval (Environment `windows-owner-test`). Never open a pull request from that branch to `main`. Delete the branch after the test. Full steps: `docs/stories/OPS-15/windows-owner-test-installer.md`.

**PT-BR.** O arquivo `windows-owner-test-installer.yml` nunca deve ficar em `.github/workflows` na `main`. Somente o `@devops` o copia, uma vez por ciclo de teste, para a branch `test/windows-owner` como `.github/workflows/windows-owner-test-installer.yml`, junto de um arquivo `apps/infra/test-owner/RUN-MARKER`; a execução só inicia quando um push altera uma linha desse marcador (commit vazio não dispara), que espera a aprovação do dono (Environment `windows-owner-test`). Nunca abra pull request dessa branch para a `main`. Apague a branch após o teste. Passo a passo: `docs/pt-BR/stories/OPS-15/windows-owner-test-installer.md`.
